Leakage prevention

A module-level FORBIDDEN set blocks future-knowledge columns from ever entering the feature matrix. Validated at training time, not just documented.

GroupKFold by race

All laps from a given race stay in the same fold. This tests genuine generalisation to an unseen event, not interpolation within a race weekend.

Model persistence

Fitted pipelines are saved with joblib alongside a JSON sidecar recording training sessions, CV scores, feature columns, and sklearn version.
